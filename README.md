Project Title: E-Commerce Order & Inventory Management Pipeline
Project Overview
Designed and built a modular data processing pipeline that manages product inventory, processes order transactions, and generates real-time business reports. The system handles everyday business logic—such as verifying item availability before completing a sale—and provides structured analytics to help teams understand sales performance and customer spending habits.

Key Achievements & Technical Highlights
Database Design: Built a relational database (RDBMS) storing customer, product, and order records with primary and foreign key constraints to prevent data inconsistencies.

Transaction & Inventory Processing: Developed automated Python workflows to process customer orders, dynamically updating stock levels while gracefully handling errors (such as out-of-stock items) using database rollbacks.

SQL Analytics & Reporting: Authored analytical queries using JOINs, aggregations, and Window Functions (RANK) to summarize customer lifetime value and rank high-value purchases for decision-making.

Quality Assurance & Testing: Wrote automated unit tests to verify business logic, ensuring system stability and preventing errors prior to deployment.

Version Control: Managed all code iterations and project structure using Git and GitHub following clean code and software engineering standards.
